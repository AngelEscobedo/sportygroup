# CLAUDE.md

Guide to running, configuring and navigating this project.

## Run it

Requirements: **Node.js 22.22+ or 24.15+** (Angular 22 engine requirement) and npm.

```bash
npm install
npm start                    # dev server → http://localhost:4200
npm run build                # production build → dist/league-list
npm test                     # unit tests, watch mode
npx ng test --watch=false    # unit tests, single run
npx prettier --write src     # format
```

## Configuration

| File                              | What it configures                                                                                                    |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `src/environments/environment.ts` | `sportsDbApiUrl` (TheSportsDB v1 + free key `123`) and `featuredLeagueId` (`4328`, English Premier League)            |
| `src/app/app.config.ts`           | Providers: `provideHttpClient(withFetch())`, global error listeners, the Material Symbols font for `<mat-icon>`       |
| `angular.json`                    | Global styles `src/tailwind.css` + `src/styles.scss`; bundle budget (700 kB warning / 1.2 MB error)                   |
| `.postcssrc.json`                 | Enables the `@tailwindcss/postcss` plugin                                                                             |
| `src/tailwind.css`                | Tailwind v4 entry: `theme` + `utilities` layers only (**no preflight**, to avoid clashing with Material)              |
| `src/styles.scss`                 | Dark Material 3 theme with Premier League-inspired overrides (`mat.theme-overrides`), brand gradients and base styles |
| `src/index.html`                  | Title and meta, Plus Jakarta Sans and Material Symbols fonts                                                          |
| `tsconfig.json`                   | `strict: true`, `strictTemplates: true`                                                                               |
| `.prettierrc`                     | Formatting rules (generated by the Angular CLI)                                                                       |

The app is **zoneless** (no `zone.js`), which is the default for new Angular 22 apps.

## Architecture

Component based, with standalone components. Every component has its own folder with separate `.ts`, `.html` and `.scss` files.

```
src/app/
├── app.ts / .html / .scss            Shell: toolbar + <app-leagues-page>
├── app.config.ts                     Providers
├── core/                             No UI
│   ├── models/league.model.ts        League, Season, API response types
│   └── services/
│       ├── request-cache.ts          Observable cache (shareReplay, in-flight de-dup, error eviction)
│       └── sports-api.service.ts     All HTTP calls; normalizes API quirks
├── features/leagues/
│   ├── state/leagues.store.ts        Signal store: source signals, computed selectors, actions
│   ├── pages/leagues-page/           CONTAINER: the only component that talks to the store
│   └── components/                   PRESENTATIONAL (input()/output())
│       ├── league-search/            Debounced search field
│       ├── sport-filter/             Sport dropdown (built from the data)
│       ├── league-list/              Responsive grid
│       ├── league-card/              Expandable card (aria-expanded, enter animation)
│       └── league-details/           Lazy badge + alternate names (rxResource)
└── shared/
    ├── components/state-message/     Empty / error state with an optional action
    └── utils/sport-icon.ts           Sport → Material Symbol icon
```

**Data flow:** `SportsApiService` → `LeaguesStore` (signals) → `LeaguesPage` → presentational components (inputs). User events flow back up through outputs to store actions. `LeagueDetails` is the exception: it calls the service directly because it only exists while a card is open.

## Conventions

- Standalone components, `ChangeDetectionStrategy.OnPush`, signal APIs (`input`, `output`, `computed`), and the new template syntax.
- HTTP only through `SportsApiService`, and every call goes through `RequestCache`.
- Styling: Tailwind utilities for layout and spacing, Material `--mat-sys-*` tokens for colors and typography.
- New config values go in `environment.ts`, never hard-coded in components.
- Tests sit next to the code (`*.spec.ts`).
- Git commits must **not** include AI co-author or attribution lines.
